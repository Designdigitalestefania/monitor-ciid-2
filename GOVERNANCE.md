# Gobernanza

## Roles

| Rol | Responsabilidad |
| :--- | :--- |
| Dirección Editorial | Decisión final. |
| Mantenedor | Revisión de PRs. |
| Contribuyentes | Propuestas y PRs. |

## Principios Rectores

1. **Veracidad periodística**: Ninguna funcionalidad permite publicar sin verificar.
2. **Decisión humana**: La tecnología asiste, el periodista decide.
3. **Transparencia**: Cambios críticos documentados.
4. **Seguridad primero**.
5. **Calidad sobre cantidad**.
