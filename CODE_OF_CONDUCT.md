# Código de Conducta

## Compromiso

Crear un entorno profesional, respetuoso e inclusivo para todas las personas.

## Comportamientos Esperados

- Lenguaje profesional y respetuoso.
- Aceptar críticas constructivas.
- Enfocarse en lo mejor para el proyecto.

## Comportamientos Inaceptables

- Lenguaje ofensivo.
- Ataques personales.
- Acoso público o privado.

## Aplicación

Reportar a fanny@monitornoticias.mx. Confidencialidad garantizada.
